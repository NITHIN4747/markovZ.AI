# NITHIN-MARKET AI

A personal autonomous market-intelligence system that continuously observes, understands, quantifies, challenges, and presents only information that matters for the Indian equity market, with global macro awareness.

## System Goals
Continuously estimate the probability distribution of what could happen next, explain the evidence behind that estimate, identify what would change its mind, and learn from its errors.

## Architecture
- **Backend:** FastAPI (Python), Celery, Redis
- **Databases:** PostgreSQL (Core), TimescaleDB (Time-series)
- **Frontend:** React + Vite + Tailwind CSS
- **AI/LLM:** Gemini API (Heavy text), Groq API (Real-time reasoning)
- **Deployment:** Docker Compose (Local-First Architecture)
